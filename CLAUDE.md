## Architecture

**OrbitOS (SprintStack)** is a team work management SaaS (Jira-like) built on edge infrastructure.

- **Frontend:** React 19 + TanStack Router (file-based) + TanStack React Query
- **SSR Framework:** TanStack Start
- **Runtime:** Cloudflare Workers (`nodejs_compat` flag, main entry `src/server.ts`)
- **Database:** Neon Serverless Postgres via `drizzle-orm/neon-http` — always use the pooler endpoint in `DATABASE_URL` for edge compatibility
- **ORM:** Drizzle ORM — schema in `src/db/schema.ts`, queries via `db` proxy in `src/db/index.ts`
- **Auth:** Google OAuth 2.0 + custom HS256 JWT stored in an httpOnly `SameSite=Lax` cookie
- **UI:** Radix UI primitives (`src/components/ui/`) + Tailwind CSS 4

## Key Patterns

### Routing

Routes live in `src/routes/`. Protected routes are under `src/routes/_authenticated/` (e.g. `_authenticated.dashboard.tsx`). TanStack Router uses file-system conventions — the underscore prefix makes `_authenticated` a layout without a URL segment.

### Server Functions

All backend logic lives in `src/server-fns/`. These are TanStack Start server functions (not edge handlers). Use `*.server.ts` naming or TanStack Start's `createServerFn` — do **not** import `server-only`.

- `src/server-fns/workspace.ts` — auth primitives: `getCurrentActor()` (validates JWT from cookie), `requireWorkspaceRole()` (RBAC check), `ensurePersonalWorkspace()` (auto-creates personal org on first login)
- `src/server-fns/functions.ts` — all CRUD: tasks, projects, timesheets, todos, links, forms

### Authentication Flow

1. Login → Google OAuth redirect → callback stores user in `profiles` table
2. JWT signed with `JWT_SECRET` (HS256) set as httpOnly cookie
3. Every server function calls `getCurrentActor()` to extract and verify the session

### Workspace Model

Every user has a **personal workspace** (auto-created). Users can also belong to **organization workspaces** via `organization_memberships`. Roles: `super_admin > admin > manager > member`. Super admin is hard-coded to `srjtheinfinity1035@gmail.com`.

### Database Proxy

`src/db/index.ts` exports a lazy Proxy so `DATABASE_URL` is only read at call time (required for Cloudflare Workers where env vars aren't available at module init).

## Environment Variables

| Variable | Where used |
|---|---|
| `DATABASE_URL` | Neon pooler connection string (server-side) |
| `VITE_GOOGLE_CLIENT_ID` | Google OAuth client ID (exposed to client) |
| `JWT_SECRET` | HS256 signing key for session tokens |

For Cloudflare deployment, these must be set as GitHub Actions secrets and as Wrangler secrets.

## Code Style

Prettier is authoritative: 100-char print width, semicolons, double quotes, trailing commas. Use the `@/*` import alias for `src/`. Keep components as React function components with TypeScript.
